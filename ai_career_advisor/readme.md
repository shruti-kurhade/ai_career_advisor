🎯 AI Career Advisor
An intelligent AI-powered Career Recommendation System that suggests suitable career paths based on user skills using Natural Language Processing (TF-IDF) and Cosine Similarity. Built with Python and Streamlit, this project helps users identify career options and skill gaps in real time.


🚀 Live Demo



📌 Overview
The AI Career Advisor analyzes user-provided skills and matches them with a curated dataset of careers. It then recommends the top 5 most relevant career paths along with:
Match score (in percentage)
Required skills comparison
Missing skill analysis
This helps users understand: ✔ Which career suits them best
✔ What skills they need to improve


✨ Key Features
   AI-based career recommendation system
   Skill matching using TF-IDF & Cosine Similarity
   Top 5 career suggestions with ranking (1–5)
   Skill gap analysis for each career
   Match score displayed in percentage
   Professional Streamlit UI
   Fully deployable web application


🧠 How It Works
   1.User enters skills (comma-separated input)
   2.Skills are converted into numerical vectors using TF-IDF
   3.Cosine similarity compares user skills with career dataset
   4.Careers are ranked based on similarity score
   5.Top 5 matches are displayed with:
   6.Match percentage
   7.Shows Missing skills
