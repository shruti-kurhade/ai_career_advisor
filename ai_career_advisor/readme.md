# 🎯 AI Career Advisor

An intelligent AI-powered Career Recommendation System that suggests suitable career paths based on user skills using Natural Language Processing (TF-IDF) and Cosine Similarity.

---

## 🚀 Live Demo
https://ai-career-advisor-r111.onrender.com

---

## 📌 Overview

The AI Career Advisor analyzes user-provided skills and matches them with a curated dataset of careers.

It recommends the top 5 most relevant career paths along with:

- Match score (percentage)
- Required skills comparison
- Missing skill analysis

This helps users understand:
- ✔ Which career suits them best
- ✔ What skills they need to improve

## ✨ Key Features

- AI-based career recommendation system
- TF-IDF & Cosine Similarity matching
- Top 5 ranked career suggestions
